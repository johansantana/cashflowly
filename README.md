This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app).

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tools used

To learn more about Next.js, take a look at the following resources:

- [Next.js](https://nextjs.org/docs) - as base framework.
- [Tailwind CSS](https://tailwindcss.com/docs/editor-setup) - for styling.
- [Hero UI](https://www.heroui.com/docs/guide/introduction) - for components.
- [Tabler Icons](https://tabler.io/icons) - for icons.
- [Shadcn/ui](https://ui.shadcn.com/docs/components/chart) - for charts.
- [Neon](https://neon.tech/docs/introduction) - as development database.
- [NextAuth](https://neon.tech/docs/introduction) - for authentication.
